# 能力：会话与登录持久化

> 状态说明：**本能力尚未实现**。以下为已确认契约。实现后本文件记录当前事实。

## 职责

让网页视图拥有一个**稳定、独立、可跨重启保持登录态**的浏览器上下文，避免因"每次启动都是全新环境"而触发异常登录风控。

## 规则

1. **分区固定**：使用一个固定的 `persist:` 分区常量。**禁止每次启动随机生成分区名**——随机分区等价于每次都是新浏览器，是最典型的异常登录信号。
2. **分区名中性**：不得包含应用名、项目名或任何可识别本工具身份的字符串（该名字会长期留在磁盘上）。
3. **登录方式**：不预设。按"哪种方式实测在固定分区下最稳定"选择（验证码 / 扫码 / 邮箱），结论在 **P2 开工前**确认并记入本文件。
4. **不共享**：不得与用户日常浏览器的 profile 混用，也不得跨目标平台复用同一分区（不同平台需各自独立分区）。
5. 会话数据只存放于分区内，应用自身的配置与状态不得写入该分区。

## 验收

- 重启应用后无需重新登录即可继续对话。
- 代码中分区名为常量，运行期未创建任何随机命名的分区目录。
- 抓包显示会话相关请求的 Cookie 完全来自该分区。

## 待同步决策

会话分区的中性命名需在 P2 开工前拍板；一旦落到用户磁盘，事后改名等于换会话（见计划的"待同步决策"表）。
