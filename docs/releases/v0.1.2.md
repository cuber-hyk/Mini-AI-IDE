# Mini-AI-IDE v0.1.2

软件更新现在有了应用内的图标和暗色浮层，查看说明、下载和安装更方便。

## 更新内容

- 编辑区顶部新增更新图标。发现新版本时显示蓝色提示点，启动时不再弹窗打断编辑。
- 点击图标或“帮助 → 软件更新…”查看当前版本和更新说明，选择下载更新。
- 浮层展示下载进度；关闭浮层后下载继续，完成后由你选择“重启并安装”。
- 更新说明支持展开全文，窄编辑区也能完整查看；检查或下载失败可以重试。
- 安装前仍会确认未保存文件，取消或保存失败时继续编辑；普通退出不会自动安装。

## 安装与升级

已安装 v0.1.0 或 v0.1.1 的 NSIS 安装版可以从原有“帮助 → 检查更新”下载并升级。完成升级后即可使用新的更新图标和浮层。

首次安装推荐 `Mini-AI-IDE-Setup-0.1.2-x64.exe`。Portable 免安装版暂不支持原地更新，需要手动下载替换。

`latest.yml` 和安装包 `.blockmap` 是自动更新所需文件，用户无需手动下载。

更新需要访问 GitHub；当前 Windows 产物未做代码签名。用户设置和网页会话目录保持不变。
