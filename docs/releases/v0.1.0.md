# Mini-AI-IDE v0.1.0

首个 Windows x64 发布版本：在本地编辑文件，手动使用内嵌 DeepSeek 网页对话，采集回复并预览、确认应用修改。

## 主要功能

- Monaco 本地编辑、多文件标签、目录和文件管理。
- 复制上下文、简洁／完整提示词及自定义输出格式。
- 只读采集模型回复，使用 SEARCH／REPLACE 精确修改，预览后确认写入，支持当前会话撤销。
- 编辑器、AI 网页和变更列表三列布局，支持调整和独立收起。
- NSIS 安装版支持应用内检查、下载和重启安装更新；未保存文件经过确认后才能安装，普通退出不自动安装。

## 下载与安装

推荐 `Mini-AI-IDE-Setup-0.1.0-x64.exe`，可选择安装目录，并支持后续应用内更新。

`Mini-AI-IDE-Portable-0.1.0-x64.exe` 为免安装单文件，不支持原地自动更新，后续版本需手动下载替换。

`latest.yml` 和安装包 `.blockmap` 是软件更新所需元数据，使用者无需手动下载。

## 使用说明

- Windows 10／11 x64，无需另装 Node.js 或 pnpm；登录网页、对话及软件更新需要联网。
- 程序不自动向网页粘贴或发送，不执行模型回复中的命令；AI 写盘须用户确认。
- 当前 Windows 产物未做代码签名，系统可能显示未知发布者提示。
- 此前没有更新功能的本地打包版本需要手动安装一次本 Release 的安装版，之后可以在帮助菜单更新。

详细使用与模型输出格式见仓库 README。
