# Mini-AI-IDE v0.4.0

本版本改进工具执行与自动协作稳定性，并优化编辑器和工作区交互。

- 支持粘贴完整工具 JSON 后手动单次执行；仍使用现有校验、权限与批次去重，并可复制诊断或结果。
- 自动采集与结果回传在明确可恢复的故障下有限恢复；来源未知、用户中断或发送状态不明时仍暂停等待处理。
- 工具结果面板更紧凑，并随可用宽度调整布局；编辑器连续输入、分栏拖动及官网加载状态得到改进。
- 安装版与开发版共用单实例保护，避免多个进程同时使用同一会话存储。

Windows x64 发布包含 NSIS 安装包、Portable、`latest.yml` 和安装包 `.blockmap`。安装包未签名。

真实官网长期连续运行及已安装旧版本的完整升级验收不由离线测试或打包校验替代。
