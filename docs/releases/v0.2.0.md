# Mini-AI-IDE v0.2.0

本版本升级本地工作区界面和工具协作流程。

- 左侧常驻多项目列表，支持添加、搜索、切换、移除与重启恢复；切换项目保持当前官网对话，不建立会话绑定。
- 中间官网与本地工具状态，右侧文件/本批改动标签及最右目录；中性深灰主题、独立目录顶栏、文件区全屏与自然恢复入口。
- 选区浮动复制保留原文；移除复制上下文菜单及全文复制，需要全文时可描述文件路径让AI请求本地读取。
- 通用本地工具、预选权限、执行状态、进程中断、真实变更快照及工具修改撤销。
- 单一自动继续开关（默认关闭），当前真实工具结果完成后按间隔回传；已有网页输入、异常或无法确认发送时暂停，不覆盖草稿或重复发送。

本次不包含多项目后台AI并行，也不包含后续Harness风格Diff列表和轮次变更记录重做。

Windows x64提供NSIS安装包及Portable。安装版更新使用latest.yml与blockmap；Portable不参与自动安装更新。产物未签名。

验证：625项源码测试及160项打包隔离自检通过，包内源码与构建结果一致，发布附件哈希/blockmap校验通过。真实官网自动发送、Windows系统DPI及本版本完整安装升级仍无完整人工验收，自动检查不替代这些项目。
