# Mini-AI-IDE v0.1.1

本版本用于检验安装版的软件更新链路。功能与 v0.1.0 一致，仅将版本号提升到 v0.1.1；作为稳定版 Release 发布，允许 v0.1.0 的安装版发现并下载。

## 更新验证

1. 在已安装的 v0.1.0 中选择“帮助 → 检查更新”，应提示 v0.1.1。
2. 选择“稍后”时不下载；再次检查或从帮助菜单选择下载。
3. 下载完成后选择“稍后”，正常退出不会自动安装。
4. 重新启动，检查更新并下载（已缓存文件会由更新库校验），选择“重启并安装”。若有未保存文件，取消应继续编辑，保存失败不能进入安装。
5. 完成更新后，“帮助”菜单显示当前版本 0.1.1；再次检查应为最新版本。核对用户设置、目录历史和 DeepSeek 登录态。

推荐使用 NSIS 安装版；Portable 暂不支持原地更新。升级仍需访问 GitHub，当前 Windows 安装包未做代码签名。

该 Release 提供安装包、Portable、`latest.yml` 与安装包 `.blockmap`。普通用户无需下载更新元数据。
