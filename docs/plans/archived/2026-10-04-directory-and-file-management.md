# 目录恢复与基础文件管理

## 目标与范围

修复目录记忆入口不一致，使 IDE 恢复上次成功打开的目录，并提供不会静默丢失编辑内容、不会跨目录复用 AI 记录的基础文件管理。

范围：单窗口、单根目录、单文件编辑；目录打开、恢复、最近记录、关闭；文件和文件夹新建、重命名、删除；文件查看、编辑、保存和手动刷新；相关编辑状态与 AI 记录生命周期。

非目标：修改 Monaco 核心、迁移到 VS Code 源码、多工作区、多标签页、恢复上次文件或光标、自动保存、外部文件自动监听、永久删除、按目录保留 AI 批次。沿用现有三列布局、文本读取限制和网页只读边界。

## 已确认的交互规则

用户于 2026-10-04 确认了以下方案。

### 目录生命周期

- 启动只恢复上次成功打开的目录，不恢复编辑文件或光标。
- 首次使用、原目录失效或用户关闭目录时，编辑区域显示打开目录及最近目录入口，AI 网页继续使用。
- 最近目录最多 5 个，按最近成功打开时间排序、去重；编辑器空白区域和“文件 → 最近打开”使用同一份记录。
- 顶部按钮、文件菜单、最近目录汇聚到同一打开流程。取消选择、编辑保护取消或打开失败时，原目录、编辑内容和记录保持不变。
- 只有成功打开后才更新当前根目录、恢复记录与最近目录。已失效的最近目录提示失败，不切换到其他目录；启动恢复失败时提示重新选择，不默认打开其他目录。
- 关闭目录回到空白状态并清除启动恢复记录，保留最近目录；下次启动保持空白。
- 保留显式命令行根目录及隔离自检入口，不让测试样例污染正常用户目录记录。

### 文件树操作

| 操作 | 规则 |
|---|---|
| 新建文件或文件夹 | 文件树顶部图标和右键菜单；选中文件夹时在其内部创建，选中文件时在其父目录创建，无选中时在根目录创建 |
| 名称输入 | 树内输入；Enter 确认、Esc 取消；名称非法或重名时提示，不覆盖原条目 |
| 创建完成 | 文件自动打开；文件夹自动展开；失败时不呈现成功状态 |
| 重命名 | 右键菜单或 F2；树内编辑名称；已打开文件同步路径，文件夹重命名同步其内部当前文件路径 |
| 删除 | 右键入口；确认中显示目标名称，文件夹明确说明包含其内容；移入系统回收站，失败则提示，禁止转为永久删除 |
| 查看和编辑 | 点击文件打开，文件夹原地展开或收起；Ctrl+S 保存 |
| 刷新 | 顶部手动刷新；重新读取目录，保留仍然有效的展开与选中状态 |

文件操作仅作用于打开根目录内的条目，不允许重命名或删除工作区根目录。操作由主进程执行，渲染进程仍只经窄 IPC 请求；不得覆盖已有目标或绕过路径权限。

### 编辑与 AI 记录生命周期

- 切换文件、切换或关闭目录、退出 IDE 时，未保存内容提供“保存／放弃／取消”。保存失败或取消时，不执行后续离开操作。
- 新建文件后自动打开也遵守未保存保护；创建和打开的失败分别显示实际结果。
- 删除当前文件或包含当前文件的目录时，先处理未保存内容，再确认删除；取消或删除失败时保留编辑器。删除成功后清空对应编辑内容。
- 重命名成功后保留当前编辑内容，更新保存目标；重命名失败时不修改编辑器路径。
- 切换或关闭目录时清空原目录的变更预览、片段基线及 AI 撤销记录；存在这些记录时，在切换前说明影响。已经写入磁盘的内容保留。
- 重命名或删除时，让受影响路径的 AI 变更与撤销记录失效并提示重新采集；文件夹操作覆盖其后代路径，其他文件的记录保留。
- 取消或失败的操作不清理记录；旧目录的异步采集、读文件、预览或写入不能在切换后污染新目录。切换流程与正在执行的写盘操作需要有明确先后次序。

目录历史由主进程设置存储负责；文件内容由磁盘负责，未保存编辑缓冲由编辑器负责。最近目录项只能引用主进程保存的用户历史，不开放渲染进程任意指定根目录的通道。

组织约束：非平凡目录生命周期使用有明确职责的 owner 模块，通过现有入口接入；不继续把独立状态逻辑堆入大型 `index.ts` 和 `renderer.js`，也不创建通用工具模块。公开入口保持稳定，文件管理只增加必要契约。

## 验收标准

1. 用户通过任一入口成功打开 B 后，正常重启恢复 B，不再回到过时的 A；目录无效时提供明确的空白状态与错误说明。
2. 最近记录最多 5 个，顺序、去重和菜单／空白区域一致；取消或失败不把无效目录写成当前目录。
3. 新建、重命名、删除、打开、编辑、保存和手动刷新可通过可见入口完成；新建或重命名不会覆盖原有文件。
4. 删除经确认进入回收站；失败可见且不会偷偷永久删除；根目录不可由文件树删除或重命名。
5. 所有离开当前编辑内容的入口遵守未保存保护，保存失败不能继续离开；重命名后保存写向新路径。
6. 目录切换后旧预览、片段基线和撤销记录不可用；同名文件也不能跨目录操作；取消或失败不丢失原记录。
7. 文件或文件夹重命名、删除后，只让受影响路径的 AI 记录失效，其他路径仍然可用。
8. 现有 Monaco 编辑、局部范围替换、输入区、三列布局和网页只读行为通过回归；新增接口不能让网页访问本地文件。

## 风险与处理

- 设置存储当前写入失败只记录日志；实现需使目录流程能识别持久化失败，不能显示“已记住”但实际未保存。
- 相对路径会在根目录改变后指向不同文件；必须连同缓存、快照及异步任务处理，不能只换文件树标题。
- 路径白名单当前主要是词法校验；有删除与目录操作后，要核对符号链接／junction 的真实路径边界，不能通过链接操作根目录外对象。
- Windows 的非法名称、保留名称、大小写和大小写专用重命名需要真实文件系统验证；以不覆盖已有目标为准。
- 回收站验证使用专用测试文件或可注入接口，不触碰用户项目文件；真实系统行为在 Electron 本地测试中确认。
- 不依赖现有自检成功数作为通过证据；记录实际通过、失败、跳过与环境限制，并对本任务新增场景单独验收。
