# 工具 JSON 手动执行

## Goal And Scope

用户已确认在工具面板粘贴完整原始JSON或mini-ai-tools围栏，先校验预览、再明确点击执行；复用当前项目权限、工具执行及持久去重。结果查看、复制，不自动回传官网，不接受repair_draft；手动批不支持attach_file，明确拒绝且不读取/运输附件。此入口不依赖官网DOM采集成功，不读取剪贴板、不模拟网页操作。

前一批已验收改动提交为3b210aa并快进合并master；当前任务分支codex/manual-tool-json。隐藏目录临时文件保留，不纳入提交。当前任务没有提交/合并/推送授权。

## Decisions And Owners

- previewToolJson(text)返回项目、批次、请求预览及主进程短期令牌；executeToolJson(token)只执行确认的原始批次。输入修改须重新预览。令牌绑定当前项目/平台/会话/修订，单次消费；项目切换、网页上下文变化或忙状态不能绕过，UI取消不执行。
- 协议解析仍使用parseToolBatch；只为完整原始JSON添加正式围栏，拒绝普通说明、多批次、结果回执和repair_draft，不修补错误正文；正文上限200000个UTF-16字符。错误显示真实诊断。
- 手动来源必须由主进程记录，执行结果、权限拒绝及校验错误都不能进入自动回传或附件运输。automatic设置不改变；已有自动倒计时/发送或本地需求发送、工具批次或后台命令忙时拒绝导入，防止覆盖执行中批次。复制仍沿既有结果入口。
- dev-split：不拆既有门面；非平凡预览令牌责任由具名manualToolJson owner管理；integration只做接线，harness继续单一执行入口并携带来源。UI放具名toolJsonPanel模块，toolHarness仅状态接线，复用当前工具区域与主题，不新增通用弹窗框架。
- 更新当前能力、上下文路由和CHANGELOG；跨来源执行/回传边界记ADR，独立只读评审，最后交用户真实UI验收。
