# 回程列表与标签栏 UI

## 已确认目标

继续当前 `codex/ai-create-missing-files` 分支，保留已有相关实现，完成用户确认的三项交互。不在此次实施中提交或合并，不增加依赖或操作官方网页。

1. 无明确文件修改线索的围栏统一归为“其他内容（只读）”，默认折叠；有范围、文件标签或元信息冲突的块保留校验与提示。其他内容不计文件数、不参与应用、不执行。
2. 删除常驻黄色诊断区，保留文件筛选与简短统计；完整诊断通过默认收起的入口查看，操作失败保留简短可见反馈，条目问题在详情说明。
3. 标签横向滚动条透明轨道、细灰滑块、无箭头，悬停增强；滚轮横滚，切换时确保活动标签可见。

沿用 dev-orient/dev-plan/dev-branch；dev-split 判定 no split：分类属于 shared/returnPath，适用性属于 ReturnPathService，主进程只适配契约；列表交互属于 changeTree/preview，标签滚动属于 editorTabs。不增加通用工具模块。设计复用 DESIGN.md、ui.css 与现有原生 details 控件。
