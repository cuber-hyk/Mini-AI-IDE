# 输入区与提示词切换 UI

## 目标与范围

落实用户确认的「上方输入区、下方操作栏」：版本切换及设置在左、复制在右；单层低对比边框，聚焦高亮；当前版本自定义状态以小圆点提示；复制显示短暂成功反馈。保留深色主题、输入自适应、持久化版本、自定义提示词和人工粘贴边界。三列布局不在本次范围。

## 实现归属

- `src/renderer/index.html`、`style.css`：局部结构及样式，复用现有图标、颜色变量与分段控件。
- `src/renderer/promptComposer.js`：输入高度、切换、自定义标记和复制反馈；从现有大文件移动这一完整 UI 责任，单入口由 renderer 初始化。不增加到 `renderer.js` 的新业务行为，其他编辑器功能不动。
- `src/main/index.ts`、`preload.ts`、`src/shared/contract.ts`：窄状态查询及广播，只传版本和自定义布尔值，保留现有公开入口。
- `test/promptComposer.test.ts` 与已有离线校验：输入、切换失败、复制失败与设置同步验证。
- 本次为页面局部布局，不推广为全项目设计规则；无新的设计系统文件或 ADR。

## 步骤与验证

1. done：调整结构和轻量样式，将输入区行为归入 owner。验证：DOM id、脚本加载、原高度边界及键盘可达性。
2. done：接通真实自定义状态及广播，复制反馈与异常处理。验证：切换后显示对应自定义状态，保存/重置实时同步，失败无成功假反馈。
3. done：构建与功能测试，生成真实 HTML/CSS 的浏览器预览。验证：宽/窄布局、短/长输入、聚焦态与复制态；明确浏览器预览和 Electron 的验证边界。
4. done：独立评审、changelog 与能力文档同步，归档计划。验证：最终 diff 只有本任务内容，文档新增项无错误。

- 复用现有颜色与控件，本次只落实输入区的局部设计；不新增设计系统合同或 ADR。
