# IDE 三列布局与操作归属

## 已确认目标

用户批准三列概念图后授权实现。编辑器（内部含目录树）→ AI 网页 → 变更列表；输入区保留上次优化。采集跟随网页，复制上下文跟随编辑器，批量应用/撤销跟随变更列表。列表按目录/文件组织，多片段展开子项，显示范围与状态，支持文件筛选。

本轮不更改 AI 网页内容、回复解析或落盘算法，不模拟网页输入/发送，不新增自动应用。布局比例随可用宽度约束；隐藏各列保留恢复入口。概念图中的网页内容只是示意，正式程序继续加载原网站。

## 模块归属与结构约束

| 模块 | 职责与边界 |
|---|---|
| `src/main/windowLayout.ts` | 纯几何计算，取代 index.ts 的上下布局算法，测试各显隐状态及边界；无 Electron 副作用 |
| `src/main/index.ts` | 应用视图 bounds、显隐、菜单与 IPC，复用统一 relayout；不累积新纯几何算法 |
| `src/renderer/preview.*` | 变更树、筛选、选中片段、集中应用/撤销和拖动右列宽度；不读写文件 |
| `src/renderer/editorToolbar.js` | 复制上下文菜单的开关/键盘/外部点击关闭；复制内容仍走现有 editor 链路 |
| `src/renderer/webbar.*` | 采集与列显隐按钮，只读采集走现有主进程通道 |
| `design-tokens.json`、`src/renderer/ui.css` | 已确认基础值与局部视图共用按钮样式；构建产出 token CSS，单一值源 |
| `DESIGN.md` | 用户已审阅概念图的布局与控件规则，运行时来源指向代码；不规定未出现的页面 |

结构分类：几何有独立可验证 owner；编辑器增加的菜单交互单独归属，保留 renderer 初始化和现有复制入口；不以行数做全仓拆分。

## 接口约定

- 保留 `ui:set-preview-panel` 通道；三列布局统一按宽度解释参数，`0` 收起，正数展开或调整；返回 `{width, visible}`。移除旧高度布局，不并存两套算法。
- `ui:chrome-state` 广播 `webVisible`、`previewVisible`、`previewWidth`（另含无障碍分隔条使用的最大宽度）；编辑器、网页工具条、变更列表共享实际显隐状态。
- 网页隐藏时变更列仍可用，网页工具条成为中间的恢复把手。变更收起后由网页工具条/菜单恢复。
- 片段保留原批次索引；树折叠和筛选仅影响显示，不能改变应用目标。应用只使用用户明确选中的片段或「全部应用」。
