# 根目录菜单与多文件标签

用户要求确认并修复树空白处无法右键新建、顶部无法切换多个文件的问题。

## 范围与默认交互

- 空白处菜单作用于根目录，提供新建文件、新建文件夹、刷新；条目菜单保留原行为。
- 打开的文件各有标签和独立 Monaco model，切换保留草稿、撤销栈与光标位置。
- 关闭脏标签时保存／放弃／取消；切换或关闭目录、退出检查所有脏标签。
- 改名同步受影响标签；删除只关闭受影响标签；AI 写回拒绝覆盖非活动标签的草稿。
- 不恢复启动前的标签，不增加分屏、拖拽排序或预览标签。

## 放置约束

沿用当前未提交目录管理分支，既有修改均属于同一功能。无需拆分既有代码；文件树继续归 fileExplorer，缓冲和模型生命周期归 editorWorkspace，标签 DOM 归 editorTabs，主进程确认归 editorSession。renderer 只负责 Monaco 适配；Do not add to: renderer.js（多文件状态机与标签 DOM）。

## 步骤与验证

1. 确认入口和现有保护：已确认只有条目菜单、单文件缓冲。
2. 补根目录菜单：文件树测试及真实 Electron 根目录新建验收。
3. 多标签与跨进程保护：缓冲、保存失败、异步旧读、改名删除、所有脏文件确认测试。
4. 集成验收：类型检查、构建、全部单测、Electron workspace 探针及既有 UI 回归。
5. 更新当前能力、设计规则、变更记录并归档；人工独立复查状态边界。未经本次提交授权不提交或合并。
