# 工具变更查看与文件树完善

## 目标与范围

工具按已选权限直接修改文件，右侧展示本批真实修改前后差异和执行状态，不再重复应用。文件树增加类型图标、资源管理器定位、绝对及相对路径复制、永久删除，同时保留移入回收站。

用户最新指示取消布局迁移：工具和需求输入区保持左侧，网页仍为独立只读视图。不增加终端、时间线、Git 历史、多批历史存储，不提交、合并、推送或发布。

## 已确认路线

- 右侧只查看工具实际变更，保存执行时的 before/after，后续编辑不能污染快照；失败与部分成功分别显示。当前批次以内存记录，不将源码另行持久化。
- 不增加第二个写盘入口；撤销复用现有工具撤销，并同步变更状态。原始路径基线、权限和未保存处理继续生效。
- 文件图标采用本地 SVG，区分文件夹开合及常见类型，未知类型通用；延续暗色、细条和具名菜单。
- 永久删除独立入口，原生确认明确目标和文件夹内容范围；处理未保存文件，失败不假称完成。保留回收站入口，不删除工作区根或越界链接。
- 资源管理器定位和复制路径由主进程验证目标与工作区身份；网页不能调用。

## 代码归属（dev-split）

现有 index.ts 与 renderer.js 不做无关拆分，只接线。实际修改记录归工具 changes 及专有 changeReview 模块，右侧沿用 preview 视图改为查看；文件管理归 FileManagementService/WorkspaceController，图标归具名 fileIcons 模块。共享 contract/preload 通道由主代理整合，避免并行写入。大入口拆分暂缓，后续职责继续增加时重新评估，不以行数为目标。

## 验收与收尾

数据来自真实执行快照，已执行文件无应用按钮；失败不伪造快照和工具身份。当前批次记录在项目/会话切换时清理；外部授权目标仅展示已获授权的记录，不能扩大编辑器文件桥。菜单目标以本次右击条目为准，空白处以根目录为准。布局未迁移。

完成后更新 DESIGN、CHANGELOG、能力文档、context-map 与必要 ADR，检查通过并独立评审后归档；需真实网页或人工确认的部分明确报告，不以离线夹具冒充。Git 写操作另等用户批准。
