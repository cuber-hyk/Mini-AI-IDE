# Mini-AI-IDE 0.3.0 发布

## Goal And Scope

用户已授权提交、合并、发布和 push，并委托判断版本号。相较已发布的 0.2.7，本次包含 ChatGPT 普通会话接入、AI 临时目录、JSON 局部恢复和草稿备份等新增能力，采用 0.3.0。发布 Windows x64 安装版、Portable 与安装版更新元数据。

不修改签名、登录分区、自动安装策略或网络边界；不纳入主目录无关的性能审计与临时目录文件，不关闭用户 IDE，不操作用户安装。

## Assumptions And Decisions

- 基线 master 68f1632，加载失败修复已在 codex/deepseek-load-failure 提交为 3021900；发布分支 codex/release-0.3.0 继承该修复。
- 更新 package.json 和 CHANGELOG；锁文件无项目版本字段，无依赖变更。
- 发布前修正既有 F3d 自检断言：当前正式模板及单测均为 16 组，旧自检仍要求 15；只改标签与数量，不放宽合法性检查。
- 复用既有打包和发布校验。先建 GitHub 草稿 Release 上传全部四项产物，核对后才公开并标为最新版本。
- 审核采用手工模式，核对版本、产物、更新清单及权限边界；之前独立评审调度因账户额度不可用，不宣称独立评审通过。
- ADR gate: not needed；沿用已有 Windows 打包和软件更新决策。
- dev-split: no split；自检只修正一条既有断言，不新增模块。
