# 回程代码块关联与范围契约

## 目标与已确认决策

- 继续 `codex/ai-create-missing-files`，保留相关新增文件功能，未经用户批准不提交或合并。
- 每个代码块独立关联附近的明确文件标题和范围；标题间允许空行，不借用其他块、当前文件或最后复制选区。
- 已有文件必须明确原替换范围，新内容长度可不同；缺少路径、范围或相互冲突时只阻塞对应块。
- 新建文件完整写入代码，范围用于统一输出格式，按实际内容展示；缺少范围或行数不符时提示。
- 无路径的 shell 命令只读展示，不执行、不参与全部应用。

决策记录：`docs/adr/2026-10-02-return-path-contract-and-trust-boundary.md`；本轮更新既有回程信任边界，无新增依赖或架构。

## 范围与模块归属

采集由 `replyCollector` 负责只读 DOM 序列；解析由 `shared/returnPath` 负责块关联；适用性由 `returnPathService` 单一入口判断；主进程适配器和变更列表显示结果。沿用现有职责，不新增通用模块，不调整文件系统权限实现，不引入依赖或网页自动化。
