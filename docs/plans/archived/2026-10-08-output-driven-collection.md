# 输出驱动自动采集

用户确认自动采集独立于发送动作/回执与会话绑定，新会话和已有会话统一发现新完成工具输出；历史基线和结果回传来源校验保留。沿用当前任务分支与已授权工作，不提交发布。不改变网页写入运输或权限。

1. 移除 AutoCollector 新轮资格与 integration 发送确认屏障，保留结束核验、历史基线和批次持久去重。验证无需点击/回执的新输出、纯对话、生成/未知/中断与重复。
2. watcher 清理本地主动首发资格，导航按 DOM 连续性判断是否保持内容观察，真正切会话等待历史加载建立基线，完整导航/项目/开关作废旧读取。验证异步历史与旧DOM残留。
3. 原生离线集成验证首发生成期间分配地址、已有会话直接新增完整工具输出、未确认发送仍按真实输出采集、历史与结果错发拒绝。
4. 全测试、构建、自检、独立只读复查；更新 ADR/能力/规则与CHANGELOG，归档计划。发送器的首页实际点击后一次地址确认属于发送职责，不以其授予采集资格。

风险：静态DOM历史恢复与瞬时完整新输出可能外观相同，以历史加载边界/生成状态与内容节点连续性建立证据，不能用发送猜测。scope仍用于执行来源与回传，不作为新输出采集门槛。


实施：AutoCollector 删除新轮授权标记，integration 删除发送回执屏障和本地主动首发采集资格。发送只走原受控sender，真实动作仅取消旧待发送结果。watcher与replyObservation共用回复根筛选，普通导航等待旧根替换，分批历史在500毫秒相关DOM安静前持续更新基线；开启时已有未知回复也等待首次完成正文作为历史。完整导航历史等待跨dom-ready保留，通知带scope并丢弃旧作用域。

验证进展：全量661测试通过、0失败/跳过；构建通过（未绑定裸标识符0，其他语义诊断105由既有检查器标为非阻断）。Electron自检PASS、无失败项，仍有Monaco worker CSP回落主线程日志，未扩本次范围。独立review复现的已有unknown历史和分批历史问题均修复，500毫秒只是加载启发边界：分批间隔超出或开启时页面尚空而后异步恢复历史仍不可严格区分，不能宣称任意延迟历史都已防住。原生fixture发现Chromium file origin与Node URL不同，watcher统一为null file scope（同sender策略），18项watcher回归通过；官方https作用域不放宽。


原生最终验证：24项Electron离线DOM夹具通过、exit0，包含无点击完整新回复、连续批次去重、先分配地址再生成、先生成再分配地址、初始历史unknown后补footer、普通导航分两次历史挂载（250毫秒间隔）不执行。未连接真实官网，不据离线夹具断言实际官网全部时序兼容。当前能力、ADR、AGENTS、context-map与CHANGELOG同步，文档检查通过。无提交、合并、发布；保留已有用户文档排版改动。
