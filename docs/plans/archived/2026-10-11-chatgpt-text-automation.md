# ChatGPT 普通对话纯文本自动协作

## 目标与已确认决策

用户确认按推荐路线推进：复用工具协议、权限、执行、复制和自动继续 owner，分别适配 DeepSeek 与 ChatGPT 网页。先完成 ChatGPT 普通对话纯文本自动执行和自动继续；程序附件上传、GPTs、项目专属对话、语音、Canvas 等特殊界面不在本轮范围。登录保持由用户推迟验证，不以页面加载或 Cookie 存在替代认证验收。

保持 automatic 单开关及已有中断、草稿保护、不确定发送不重试、历史不重放、执行/发送期间阻止平台切换的规则。自动继续只作用于活动平台；普通对话首页首发可一次性交接到同源新会话。ChatGPT 附件请求须明确停止上传，不得静默丢弃。网页不新增 preload、IPC 或文件桥；不使用 Node AI HTTP、CDP、驱动或模拟键盘。OpenAI 个人服务条款限制程序化提取输出已向用户说明，技术验证不代表获得平台许可。

## 事实来源与代码放置

当前平台任务分支 codex/chatgpt-web-platform；相关未提交平台接入继续保留。无关审计和 tools/audit-background-history.cjs 不修改、不纳入任务。

- 平台与活动视图：webPlatformController / index；只在入口接线，不向 index 添加 DOM 规则。
- 回复采集、完成判断与变化监听：replyCollector、tools/replyObservation、tools/replyChangeWatcher；ChatGPT 选择器与只读脚本放在具名 chatgptPage owner。
- 受控网页写入仍仅 webComposerSender；支持平台专属控件，保留单次运输和取消流程。
- 执行/权限/复制/回传：tools/integration 复用原 owner，只增加活动网页重新绑定与附件边界。
- UI 沿用现有顶栏、需求输入、自动继续开关，按活动平台显示能力，无新布局。

dev-split: local owner。不按行数重构，不复制执行引擎，不引入通用浏览器自动化抽象。共享脚本仅允许只读；全部 DOM 写入仍归 webComposerSender。

## 验收与风险

可证明的闭环是：新完成规范回复 → 按权限实际执行 → 当前整批真实结果一次回传 → 新回复继续执行。旧平台、历史、生成中、中断、未知、取消批次不得进入该闭环。ChatGPT DOM 可变化，识别失败应如实暂停，不能猜测按钮或以安静时间替代完成判断。真实网站验收与登录保持分别记录；测试无跳过才可称全部通过。

ADR gate: needed（扩展现有平台/发送契约）；design_system_impact: update（现有平台能力提示）；changelog/distill/check gates: needed。旧文档校验基线 5 errors / 3 warnings 需增量区分，不修无关归档记录。
