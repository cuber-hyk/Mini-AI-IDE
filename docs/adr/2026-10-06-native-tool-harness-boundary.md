# ADR：通用本地工具与受限网页能力

## Context

用户确认 AI 生成规范工具请求，IDE 采集、管理权限、执行并返回结果；结果回传使用 `docs/adr/2026-10-07-automatic-result-return-boundary.md` 的限定授权。用户预选三种权限，允许完全访问及自动继续；IDE 不针对网站或游戏设计诊断流程。

## Decision

- 本地工具由主进程 owner 执行，AI 网页仍独立且无本地 IPC；只读采集与限定结果 sender 分属隔离世界，网页不获得工具能力。编辑器保留沙箱及项目内文件桥；工具控制仅接受编辑器主 frame。
- 使用唯一正式 mini-ai-tools JSON 批次，参数、依赖与冲突先由确定性代码校验；示例和工具结果不递归解释为调用。
- 所有实际文件读取、修改与命令统一使用工具请求，手动采集也拒绝旧文件操作文本。自然语言用于讨论和澄清。自定义提示词原文保留为补充，所有有效复制入口保留强制执行协议。
- 输入框底部预选请求批准、精确规则、完全访问。IDE 发起询问；拒绝不执行并返回 permission_denied。规则绑定请求、实际目标及项目配置和直接引用脚本指纹。
- 完全访问在当前账户内访问项目外文件和执行联网命令，不提权。原生子进程联网是工具行为，不允许主进程包装 AI HTTP 或建立任意网页代理；唯一网页写 owner 只能回传符合新 ADR 的当前批次工具结果。
- 修改复用 FileService/ReturnPathService。外部目标使用隔离文件服务，不能扩大编辑器 IPC 根目录。真实路径别名用于冲突和所有打开文档的草稿检查。
- 未保存文件继续时采用 AI 结果 C，替换草稿 B；停止保留 A/B。不合并 B，不先保存 B，仍复核完整预览原文与文件身份；处理策略可记住。
- 自动继续沿用 automatic 默认关闭，可启用并保存；包含自动采集、权限执行和整批真实结束后限定结果回传。发送间隔为 0–300 整数秒，默认 3，无轮数参数；关闭优先取消计时和待发送，不中断当前本地工具。启用、重启、导航建立历史基线。正文和生成状态来自同一次同步只读 DOM 快照。状态未知时提示手动确认；生成中手动入口也不执行工具。
- 自动采集使用隔离上下文中的只读 MutationObserver；只有回复与状态控件变化后才合并通知，不使用固定轮询。隔离上下文仅保存观察器、待通知标志、一次合并计时器及清理所需状态，不向网页主世界写入变量或暴露桥。通知只触发只读检查，生成中不散列或解析全文；确认新回复完成后，执行仍以正文和状态的同一完整快照为准。启用/导航进行一次历史基线初始化，关闭/销毁清理监听。
- 为区分异步加载的历史回复，隔离上下文只读识别真实用户点击原生发送/重新生成/继续生成按钮或 Enter 发送；Shift/修饰键回车、输入法回车、合成事件不记新轮。不读取输入内容，动作本身不触发采集。导航后没有本会话新轮标记的内容只更新历史基线；消费旧轮通知使用导航检查屏障。空新对话首次发送标记可随自动分配的会话地址保留一次，发送时是否为空由当时 DOM 记录；自动采集确认完成、手动采集成功、其它用户点击、非输入区键盘动作或输入区历史导航快捷键清除该关联。自动完成只清对应已消费轮，保留随后真实发送的新轮；手动成功同时消费待通知的旧动作，避免带入用户切换的历史。
- 继续生成只识别输入区外可见、可用且标签明确的原生按钮，允许最新唯一回复 frame 的正文外页脚及独立原生控件，排除历史回复、正文及代码卡。中断表示等待用户继续，不等同完成，不散列或自动采集半成品。真实续写动作重新赋予检查资格，完整回复结束后读同一快照并校验；不修复 JSON 或自动重试执行失败，持久去重仍有效。
- 执行前原子记录批次，稳定会话键排除追踪参数。重启中断标记 unknown，不自动重放。持久化不保存正文和命令输出。
- 内存结果正文、界面和复制仅最近一轮；新轮失败不复制旧结果。防重放元数据继续保留，重启后只在用户重新采集该批时展示其历史状态。
- 本次新批全部处理结束产生一次当前轮完成事件，本地 UI 默认短暂动画、成功/错误状态提示；短音效默认关闭并保存用户选择。事件 ID 在主进程生命周期单调递增；初始化、重复批、历史恢复不产生新提示，切项目/会话清空事件。
- 用户授权当前工具批次真正执行结束后自动复制整批结果一次，覆盖读取、搜索、修改与命令，默认开启、可关闭。工具执行失败输出同样保留；后台启动、全部未执行、取消、未知、历史恢复、配置改变及界面状态查询不自动写剪贴板，项目/会话切换作废待复制输出。复制失败单独提示，保留手动重复制。自动结果回传直接使用与复制同源的真实整批结果，不读取剪贴板；关闭或暂停时由用户粘贴发送。
- 无效工具 JSON 整批不执行、不预约，在工具结果列表显示批次校验失败卡片，包含原生解析原因、可得的正文行列与短定位片段。统一复制回执用 batch_error 承载错误、tool_results 为空，不伪造不可解析的工具名和请求 ID；不联网格式化或修复 JSON。诊断只保留最近轮内存，切换项目/会话清空。
- 任务真实启动后记录时长，主进程退出后冻结；本地 UI 仅在活动任务期间刷新秒数。每条运行命令直接提供独立中断，目标以当前项目、会话、批次和请求身份核验，仅清理对应 IDE 所属进程树，不取消其他命令或剩余无依赖请求；停止失败保留事实与可重试的身份，主 shell 退出时长和残余树待清理状态分别显示。退出清理仍统一停止全部所属命令。

## Alternatives Considered

- 单靠文字稳定会在生成暂停时提前执行，未采用。
- 应用专用排错违背通用工具职责，未采用。
- 工作目录不能作为限制子进程访问范围的沙箱，未采用。

## Consequences

shell 可用性由本机决定，缺少 Bash 如实失败。只管理 IDE 持有并可核对身份的进程及后代，不承诺管理主动脱离父子关系的守护进程。原文核验不提供跨进程文件锁；逐文件写入后续遇到系统错误可能部分成功，必须返回真实结果。工具修改使用已有计算、基线及撤销引擎；AI 修改统一使用 apply_changes，正式工具不能与额外文件操作块混用。
