# 本地项目显式绑定官网会话并双向同步

## Context

用户需要在项目下收藏重要官网对话，支持点击切换与官网选择回同步。官网大量临时对话没有项目归属，完整历史镜像既不能可靠推断归属，又依赖侧栏分页/DOM。现有按平台及账号复用原生视图、工具作用域及串行项目切换需继续维持。

## Decision

- 项目下按“平台·本地账号备注”分组，用户显式选择将当前正式网页会话绑定到某个已注册项目。任何导航、启动、首发与标题变化均不创建关联。
- 以平台、稳定本地账号编号、正式会话 ID 定义唯一身份；一个会话只有一个项目归属，不提供迁移功能。解绑只删除本地元数据；不镜像或删除官网对话。
- 主进程独立版本化元数据为绑定事实源；不读取认证、官网存储、正文或私有 API。仅普通正式路径有效，本地窄入口只接受项目索引与绑定 ID，导航从已验证身份构造。
- 项目按钮只切本地，具体会话按钮联动平台/账号/官网。独立于 automatic 的主 frame 导航监听双向同步选中；后台视图不参与，未绑定会话保留当前项目。
- 官网引起跨项目切换静默保存全部脏文件，成功后切根；本地其他切换与退出沿用原确认。失败保留草稿/项目，网页不回退，暂停不匹配工具活动并提示。旧异步结果不能改变后续导航意图，历史和旧回传资格不因切换复活。
- 一次仅一个活动本地项目与官网；继续复用每平台/账号视图，不为每个会话创建常驻渲染器。

## Alternatives

- 自动收录所有访问/新建会话：增加临时噪声且归属易错，用户明确选择显式收藏。
- 读取并镜像官网全部历史：侧栏不保证全部加载，且没有本地归属，范围与维护成本过大。
- 每会话缓存原生视图：便于保留局部网页状态，但增加资源、后台执行及运输管理复杂度，不属于本次需求。
- 跨项目都弹确认：网页导航已发生，反复提示打断使用；用户明确授权该入口静默保存，失败才报告。

## Consequences

绑定列表可跨重启保留，平台变化不影响项目重要会话的组织；标题是本地绑定时快照。网址不可达、账号退出或官网更改普通路径仍需用户处理，不能以元数据证明官网身份或可用性。移除本地项目不删除会话绑定或官网内容，重新加入同路径项目可以继续使用其已保存记录。

完整的网页草稿、生成过程与滚动状态不由本地收藏记录托管；真实官网导航与账号可用性另做人工验收。工具权限、唯一 DOM 写入 owner、真实 UA 和分区规则保持原边界。
