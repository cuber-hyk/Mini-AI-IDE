# 手动工具JSON执行与官网来源隔离

## Context

官网结构变化可能使自动/手动采集都失败。用户已确认将复制的完整工具JSON粘贴到本地工具面板，预览后明确执行。粘贴本身不能证明该请求来自当前官网最新回复，不能复用官网来源的自动回传资格。

## Decision

只允许编辑器主frame具名预览与执行入口。完整原始JSON或唯一mini-ai-tools围栏仍使用正式协议校验，原始JSON仅增加围栏，不修补内容、不解释正文嵌套示例；最多200000个UTF-16字符。预览展示当前项目绝对路径、批次ID和全部请求参数；主进程保留短期单次令牌绑定的原批次，执行不接收新正文。项目/会话/平台修订变化作废预览，忙状态阻断，输入编辑后必须重新预览。

复用工具harness、权限和持久去重，不创建第二执行器。手动来源随选择与去重记录保留，结果仅查看/复制，不能进入自动继续、批次诊断回传或具名附件回传。automatic配置保持原值；后续新的官网批次继续正常流程。重复或恢复的手动记录也不获得回传资格。手动入口不接受repair_draft；attach_file请求明确失败，不读取/暂存/上传。

用户通过官网手动复制和粘贴命令，程序不读取剪贴板，不写网页。完成结果仍按原复制设置处理。暂停/失效不重试、预览正文不保存磁盘或日志。

## Consequences And Verification

采集失败时有可审查的本地执行入口，同时保留权限、去重及官网发送边界。代价是用户自行将真实结果复制给AI，手动入口无法恢复官网补丁草稿或上传附件。必须验证错误零执行、重复/冲突去重、权限拒绝、作用域变化、持久记录来源、自动开关切换和旧令牌重放，以及下一官网新批正常回传；UI预览必须安全纯文本、明确目标项目。


## Validation

用户已确认入口与回传边界；实现通过后端118项关联、UI67项关联测试及最终1059项全量测试（0失败、0跳过），类型检查、构建及原生自检通过。独立前端评审46项、后端19项聚焦测试通过，无阻断发现。执行入口ok表示批次已接纳处理，单项结果以工具列表真实状态为准；去重范围继续为项目+会话，不提供跨会话全局去重。实际入口体验等待用户验收，实施计划保持active。
