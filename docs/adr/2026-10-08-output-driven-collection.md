# 输出驱动自动采集与独立结果回传

用户确认 automatic 开启后，新的完成工具输出可自动采集，不要求预先绑定会话、识别发送动作或收到发送成功回执。

采集资格来自历史基线之后的实际回复内容及结束证据。历史等待期间观察到新生成时，生成证据与历史加载通知分离并跨150毫秒合并保留；完整快照可能晚于生成结束，不能因此吞掉首轮。关闭或再次导航使旧证据失效。生成/中断/未知状态不执行，正式协议、项目权限与持久去重继续核验。开启时现有回复作为历史；真正切会话时等待目标历史DOM建立基线，首页同文档地址分配用回复节点/生成状态连续性或一次性的短期提交记录识别；官网可信发送点击/回车和本地主动发送写入同一8秒记录，其他真实动作取消旧交接，节点/生成兜底不能恢复被取消的交接；新的已识别发送可以重新建立记录。导航消费及监听重建使旧记录失效。已确认的首轮地址交接结束遗留历史等待，保留正文去重及真实生成证据。会话地址用于区分历史加载和批次来源，不为新输出授予采集资格。

发送器仍只接纳官方 origin、唯一空输入和已知控件，一次点击后未知不重试。发送失败不能屏蔽已经真实生成的新工具回复。结果回传必须复核执行来源的项目、会话和批次，不能发到后来切换的聊天。真实用户动作仍只读识别，用于首页地址连续性判断及取消旧待发送结果，不用于采集授权。

单一采集流程适用于官网手动需求、本地需求及工具结果后续回复，不设置发送回执屏障或本地主动首发资格。短期记录只消除首页导航的历史加载歧义，不能跳过完成快照、协议、权限及持久去重检查；没有记录时仍接受真实回复/生成连续性证据。网页没有新写入或本地桥能力，网络与身份边界不改变。

历史加载采用500毫秒相关DOM安静窗口，仅管理加载基线，不证明AI回复结束。历史分批间隔超过窗口时仍有不可辨识风险；历史恢复与未观察到生成过程的瞬时完整回复可能有相同DOM；导航加载阶段以历史基线优先，不通过猜测发送或重试执行补偿。原生离线测试不能替代官网现场验证。
